# Guide to WHM Plugins - ACL Reference Chart

## Introduction

cPanel & WHM ships with a default list of Access Control Lists (ACLs) and privileges. You can assign ACLs and privileges to WHM users in WHM's [*Edit Reseller Nameservers and Privileges*](https://docs.cpanel.net/whm/resellers/edit-reseller-nameservers-and-privileges/) interface (*WHM  >> Home >> Resellers >> Edit Reseller Nameservers and Privileges*).
