# Look up API token details

This function looks up an API token’s details based on the token itself.

Endpoint: GET /api_token_get_details
Version: 11.138.0.6
Security: BasicAuth

## Query parameters:

  - `token` (string, required)
    The API token.
    Example: "GVJWD78FF12NMBFKYKPS9BJ483C0XSQH"
