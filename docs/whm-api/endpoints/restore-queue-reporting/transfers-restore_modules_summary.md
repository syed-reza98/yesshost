Version: 11.138.0.6
Security: BasicAuth

  - `data.modules.module` (string)
    The module's name.

  - `data.modules.notes` (array)
    Notes about the module, if any exist.

  - `data.modules.restricted_available` (integer)
    Whether the module is available under a
[restricted restore](https://go.cpanel.net/whmdocsTransferorRestoreacPanelAccount#restricted-restore).

* 1 — The module is available under a restricted restore.
* 0 — The module is not available under a restricted restore.
    Enum: 1, 0

  - `data.modules.restricted_summary` (array)
    A description of the module's behavior when the transfer uses a restricted restore.

  - `data.modules.summary` (array)
    A description of the module's behavior when the transfer does not use a restricted restore.

  - `metadata` (object)

  - `metadata.command` (string)
    The method name called.
    Example: "restore_modules_summary"

  - `metadata.reason` (string)
    The reason the API function failed when the metadata.result field is 0. This field may display a success message when a function succeeds.
    Example: "OK"

  - `metadata.result` (integer)
    * 1 — Success.
* 0 — Failed. Check the reason field for more details.
    Enum: 1, 0

  - `metadata.version` (integer)
    The version of the API function.
    Example: 1
